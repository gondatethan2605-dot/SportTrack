# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/703aeac0-c9b6-4ef5-9882-a00baf5e7033

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`


## v7.4 — mode Répétitions / Timer
Les exercices d'un programme peuvent maintenant être configurés en mode Répétitions ou Timer. Une cadence de référence par exercice estime automatiquement l'équivalence temps/répétitions. En séance, le mode Timer lance un compte à rebours par série et valide automatiquement la série à la fin.
